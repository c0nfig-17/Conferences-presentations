# *Métodos de Persistencia en Windows - Hackén 2026*

Este repositorio recoge la documentación asociada a la ponencia **"Métodos de Persistencia en Windows"**, presentada en  [**Hackén 2026**](https://hacken.es/)

## Materiales

- Presentación oficial utilizada durante la ponencia.
- Paper con el contenido completo y ampliado de la charla.
- Recursos y referencias adicionales relacionados con técnicas de persistencia en entornos Windows.
